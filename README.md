# ربات دانلودر اینستاگرام به تلگرام

هر ۱۵ دقیقه پیج‌های ثبت‌شده در `config.yaml` را بررسی می‌کند و پست یا استوری تازه را مستقیم به بات تلگرام تو آپلود می‌کند. اجرا روی زمان‌بند رایگان گیت‌هاب اکشنز، بدون سرور.

## فایل‌ها

- `bot.py` — هسته‌ی کار: گرفتن پست و استوری تازه، دانلود، آپلود به تلگرام.
- `config.yaml` — پیج‌هایی که دنبال می‌کنی.
- `make_session.py` — یک بار روی کامپیوتر خودت اجرا می‌شود تا کوکی نشست بسازد.
- `state.json` — شناسه‌ی چیزهای دیده‌شده. ربات خودش این فایل را می‌سازد و در هر اجرا به ریپو کامیت می‌کند تا تکراری ارسال نشود.

## راه‌اندازی

ریپو ساخته شده: `jacktony2001/instagram-telegram-poller` (خصوصی). برای بالا آمدن ربات فقط دو کار لازم است.

۱. در BotFather یک بات بساز و توکنش را بردار. بعد پیامی به بات بده تا `chat_id` خودت را پیدا کنی (مثلاً از `@userinfobot`). این دو را با نام‌های `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` در Settings → Secrets and variables → Actions ثبت کن.

۲. یک بار روی کامپیوتر خودت نشست اینستاگرام بساز:

```bash
.venv/Scripts/python make_session.py نام_کاربری_اینستاگرام      # ویندوز
python3 make_session.py نام_کاربری_اینستاگرام                    # لینوکس و مک
```

رمز را می‌پرسد و موقع تایپ نشان نمی‌دهد. اگر تایید دومرحله‌ای داری، اول کد شش‌رقمی را در متغیر `IG_2FA_CODE` بگذار و بعد اجرا کن. در آخر یک رشته‌ی طولانی base64 چاپ می‌کند؛ آن را با نام `IG_SESSION_B64` ثبت کن و اسکرین‌نام را هم با نام `IG_USER`.

اگر پایتون محیط پروژه را نداری، یک بار بسازش:

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
```

۳. در `config.yaml` پیج‌های هدف را بنویس و push کن. بعد از تب Actions یک بار Run workflow را بزن؛ از آن به بعد خودکار هر ۱۵ دقیقه اجرا می‌شود.

## نکته‌های مهم

- اکانت دوم باید پیج‌های خصوصی را فالو داشته باشد، وگرنه چیزی از آن‌ها نمی‌آید.
- اگر نشست بعد از مدتی از کار افتاد، ربات در لاگ خطای لاگین می‌دهد؛ فقط مرحله‌ی ۳ را تکرار کن و `IG_SESSION_B64` را عوض کن.
- در اولین اجرا فقط ۱۰ آیتم تازه از هر پیج می‌رود تا تلگرام پر از اسپم نشود. برای تغییرش `MAX_NEW_PER_RUN` را به‌عنوان variable در Actions تنظیم کن.
- ریسک اصلی محدودشدن خودِ اکانت دوم است. تعداد فالوهای کم و فاصله‌ی ۱۵ دقیقه‌ای معمولاً امن می‌ماند، اما تضمینی وجود ندارد.
- دسترسی write روی ریپو لازم است، چون `state.json` دوباره کامیت می‌شود.
